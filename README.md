# MindBalance — трекер ментального состояния

PWA-приложение для ежедневного отслеживания настроения, тревожности и энергии.
Ключевой принцип: «Никакого давления» — поддерживающий тон, пастельные тона, плавные анимации.

## Возможности

- **Онбординг** (3 экрана): приветствие с дисклеймером, напоминания, выбор параметров
- **Ежедневный чекин** (< 30 сек): 5 личиков настроения, до 3 чувств, шкалы (энергия / тревожность / сон), контекст дня, заметка с авто-сохранением и голосовым вводом
- **Дыхательное упражнение**: мягкая помощь при настроении ниже 3 (3 цикла вдох-выдох)
- **Аналитика**: график за 7/30/90 дней (Recharts), бережные инсайты, календарь месяца, экспорт отчёта PDF
- **Профиль**: редактирование тегов, шкалы, тёмная тема, напоминания, SOS-кнопка (телефоны доверия), полное стирание истории
- **Приватность**: данные только в localStorage, без сервера и регистрации
- **PWA**: устанавливается на телефон, работает офлайн (service worker)

## Стек

React 18 (UMD + Babel) · Tailwind CSS (CDN) · Recharts · Lucide Icons — без сборки, один файл.

## Запуск

Открыть `index.html` в браузере (или любой статический хостинг).

## Дизайн-код

Пастельная палитра: шалфей `#A8BCA1`, лаванда `#B8A9D9`, тёплый песок `#E8D5B7`.
Тёмная тема — через класс `dark`. Анимации ≥ 0.3s, без резких переходов.
